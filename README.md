## 🌌 About The Project

**Bluetooth Messenger** is an offline messaging application designed to make communication possible without relying on the internet.

Using Bluetooth technology, users can discover nearby devices, establish connections, and exchange messages directly.

No internet. No cloud servers. No subscriptions. Just direct device-to-device communication.

Our goal is to create a simple, beautiful, and reliable messaging experience that works even when traditional connectivity is unavailable.

 🌐 Live Website
Try the website: https://mesh-chat-connectx.lovable.app/

## ✨ Key Features

- 📡 **Bluetooth Discovery** — Discover nearby Bluetooth-enabled devices.
- 💬 **Private Messaging** — Exchange messages directly between connected devices.
- 👥 **Group Chats** — Communicate with multiple connected users.
- 🔒 **Secure Communication** — Protect conversations with encryption.
- 📁 **File Sharing** — Share images and files between supported devices.
- 💾 **Local Storage** — Save conversations using an offline database.
- 🔔 **Notifications** — Get notified about incoming messages.
- 🎨 **Modern UI** — Enjoy a clean, premium dark-themed interface.
- 🔄 **Auto Reconnection** — Reconnect when a supported connection drops.
- 😀 **Message Reactions** — React to messages with emojis.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project

```bash
cd Bluetooth-Messenger
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate Environment

**Windows:**

```bash
venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash

```

## 📱 How It Works

1. Launch the application on two Bluetooth-enabled devices.
2. Enable Bluetooth on both devices.
3. Discover nearby devices.
4. Select a device and establish a connection.
5. Start exchanging messages without internet.

**Note:** Both devices must support the implemented Bluetooth communication protocol. Actual functionality depends on the operating system and Bluetooth hardware.
